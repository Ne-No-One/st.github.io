# 🎨 Інструкція по завантаженню шарів в Адмін Панелі

## 📋 Огляд

В адмін панелі тепер доступна повна підтримка системи шарів для створення динамічного дизайну товарів. Ви можете завантажувати окремі зображення для кожного шару та створювати складні візуальні ефекти.

## 🎯 Як Додати Колір з Шарами

### 1. Перейдіть в Адмін Панель
- Відкрийте `python run_admin_panel.py`
- Перейдіть до розділу **"Головний товар"**

### 2. Заповніть Основні Поля
- **Назва кольору**: Наприклад "Червоний", "Синій", "Рожевий"
- **Hex код**: Формат `#ff0000` (червоний), `#0000ff` (синій)
- **URL основного зображення**: Посилання на базове фото букета

### 3. Завантажте Шари (Опціонально)

#### 🟢 **Текстура пакувального паперу**
- **Призначення**: Нижній шар, текстура упаковки
- **Приклад**: Фото крафт-паперу, тканини, фольги
- **Ефект**: Стане фоном під букетом з накладанням кольору

#### 🟡 **Зображення маски**
- **Призначення**: Середній шар для кольорового ефекту
- **Приклад**: Чорно-біле зображення для маскування
- **Ефект**: Визначає де застосовується колір з `mix-blend-mode`

#### 🔵 **Зображення квітів**
- **Призначення**: Верхній шар, декоративні елементи
- **Приклад**: Додаткові квіти, стрічки, бантики
- **Ефект**: Відображається поверх всіх інших шарів

## ⚙️ Схема Роботи Шарів

```
┌─────────────────────────────────────┐
│  🔵 Шар квітів (z-index: 3)        │  ← Верхній шар
├─────────────────────────────────────┤
│  🟡 Кольорова маска (z-index: 2)   │  ← Накладання кольору
├─────────────────────────────────────┤
│  📷 Основне зображення (z-index: 1) │  ← Базове фото
├─────────────────────────────────────┤
│  🟢 Текстура паперу (z-index: 0)   │  ← Нижній шар
└─────────────────────────────────────┘
```

## 🎨 Як Це Працює

### При Виборі Кольору:
1. **Активується текстура паперу** з обраним кольором
2. **Накладається кольорова маска** з ефектом multiply
3. **Показується шар квітів** (якщо завантажено)
4. **Основне зображення** залишається в центрі

### При Зміні Кількості:
1. **Змінюється основне зображення** на відповідне кількості
2. **Шар квітів оновлюється** (якщо є варіант для цієї кількості)
3. **Кольор повторно застосовується** до нового зображення

## 📱 Панель Тестування

На сайті доступна панель для тестування шарів:
- **Скинути шари** - очистити всі ефекти
- **Папір** - включити/виключити шар упаковки
- **Маска** - включити/виключити кольорову маску
- **Квіти** - включити/виключити шар квітів

## 💡 Поради по Завантаженню

### ✅ **Рекомендації:**
- Використовуйте зображення з однаковими розмірами (наприклад 500x500px)
- Для масок використовуйте контрастні чорно-білі зображення
- Текстури паперу повинні бути нейтральними кольорами
- Зображення квітів можуть мати прозорий фон (PNG)

### ❌ **Уникайте:**
- Занадто яскравих текстур паперу
- Кольорових зображень для масок
- Зображень з дуже різними пропорціями
- Занадто великих файлів (краще до 1MB)

## 🔧 Налагодження

### Якщо шари не відображаються:
1. Перевірте правильність URL зображень
2. Переконайтеся що зображення доступні публічно
3. Відкрийте консоль браузера для перевірки помилок
4. Використайте панель тестування для діагностики

### Якщо кольори не змінюються:
1. Перевірте hex-код кольору (формат #rrggbb)
2. Переконайтеся що маска є контрастною
3. Спробуйте іншу текстуру паперу
