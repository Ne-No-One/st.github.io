## 🎬 Сценарій використання

### Користувач додає товари в кошик:

**Крок 1** - Кошик порожній:
```
Прогрес до бонусів
[░░░░░░░░░░] 0₴ / 500₴
```

**Крок 2** - Додано на 300₴:
```
Прогрес до бонусів  
[▓▓▓▓▓▓░░░░] 300₴ / 500₴
```

**Крок 3** - Додано на 600₴ (досягнуто знижку):
```
🎉 Активні бонуси (1)
[▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░] 600₴ 💰 Отримано!

┌─────────────────────────────┐

│ 💰 Знижка 5%            ✓   │ ← З'явився в підсумку!
```

**Крок 4** - Додано на 1200₴ (досягнуто все):

## 💡 Ключові особливості

✅ **Прогрес-бар**:
- Бонуси показуються **ТІЛЬКИ коли досягнуто** (`cartTotal >= milestone.amount`)
- Консоль лог для дебагу кожного етапу
- Компактно в прогрес-барі + детально в підсумку

✅ **Геолокація**:
- SELECT з усіма містами (не тільки input)
- Можна ввести будь-яке місто вручну
- Постійний індикатор в хедері
- Колір показує доступність доставки

✅ **Подарунки**:
- Вибір зі списку додаткових товарів
- Або введення власного варіанту
- Пріоритет: custom → select
