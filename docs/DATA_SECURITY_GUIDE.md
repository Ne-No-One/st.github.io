## 🔐 1. ШИФРУВАННЯ ДАНИХ

### 1.1 Що шифрується

Автоматично шифруються наступні поля в замовленнях:
- ✅ `customer_name` - Ім'я клієнта
- ✅ `customer_phone` - Телефон клієнта
- ✅ `customer_email` - Email клієнта
- ✅ `delivery_address` - Адреса доставки

### 1.2 Алгоритм шифрування

**Використовується:** Fernet (symmetric encryption)
- Базується на AES-128 в режимі CBC
- HMAC для автентифікації
- Timestamp для захисту від replay атак

**Генерація ключа:**
```python
# Використовується PBKDF2 з 100,000 ітерацій
kdf = PBKDF2(
    algorithm=hashes.SHA256(),
    length=32,
    salt=b'flower_shop_salt_2025',
    iterations=100000
)
```

### 1.3 Як це працює

#### Збереження замовлення:
```python
# 1. Клієнт відправляє дані
order_data = {
    'customer_name': 'Іван Петренко',
    'customer_phone': '+380671234567',
    'customer_email': 'ivan@example.com',
    'delivery_address': 'вул. Хрещатик, 1'
}

# 2. Система шифрує чутливі поля
encrypted_order = encrypt_order_data(order_data)
# {
#     'customer_name': 'gAAAAABl...',  # Зашифровано
#     'customer_name_encrypted': True,
#     ...
# }

# 3. Зберігається в data.json
```

#### Читання замовлення:
```python
# 1. Завантажується з data.json (зашифроване)
order = json_manager.get_order(order_id)

# 2. Система автоматично дешифрує
decrypted_order = decrypt_order_data(order)

# 3. Відображається в адмін-панелі (розшифроване)
```

## 🗑️ 3. АНОНІМІЗАЦІЯ СТАРИХ ЗАМОВЛЕНЬ

### 3.1 GDPR вимоги

Згідно з GDPR, персональні дані мають зберігатися тільки стільки, скільки необхідно для бізнес-цілей.

### 3.2 Автоматична анонімізація

**Налаштування:**
```env
# .env файл
PERSONAL_DATA_RETENTION_DAYS=365  # Зберігати 1 рік
AUTO_DELETE_OLD_ORDERS=False      # Анонімізувати, не видаляти
```

**Що відбувається:**
- Замовлення старше 365 днів автоматично анонімізуються
- Персональні дані замінюються на "АНОНІМІЗОВАНО"
- Статистика та фінансові дані зберігаються
- Додається мітка `anonymized: true`

### 3.3 Ручна анонімізація

**Команда:**
```bash
# Анонімізувати замовлення старше 365 днів
python manage.py anonymize_old_orders --days=365

# Показати які замовлення будуть анонімізовані (без зміни)
python manage.py anonymize_old_orders --days=365 --dry-run

# Анонімізувати замовлення старше 180 днів
python manage.py anonymize_old_orders --days=180
```

**Результат:**
```
============================================================
🔒 АНОНІМІЗАЦІЯ СТАРИХ ЗАМОВЛЕНЬ
============================================================
📅 Анонімізуємо замовлення старше 365 днів
✅ Успішно анонімізовано 12 замовлень
============================================================
```

### 3.4 Що зберігається після анонімізації

**Зберігається:**
- ✅ Номер замовлення
- ✅ Дата створення
- ✅ Сума замовлення
- ✅ Товари
- ✅ Статус
- ✅ Спосіб оплати

**Видаляється:**
- ❌ Ім'я клієнта → "АНОНІМІЗОВАНО"
- ❌ Телефон → "***"
