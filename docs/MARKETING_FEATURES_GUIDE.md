# 🎯 Путівник по маркетинговим функціям

## 📊 Прогрес-бар з бонусами

### Як це працює:

#### 1️⃣ **Налаштування в адмін панелі**
- Перейдіть: `/admin-panel/marketing/`
- Вкладка: **Прогрес-бар**
- Натисніть: **Додати етап**

#### 2️⃣ **Створення етапу**
```
Сума: 500 грн
Назва: Знижка 5%
Повідомлення: Додайте ще {amount} грн для знижки!
Колір: #f59e0b (помаранчевий)

Винагороди (можна обрати все відразу):
☑ Знижка: 5%
☐ Безкоштовна доставка
☐ Подарунок: (оберіть зі списку або введіть)
```

#### 3️⃣ **Де відображаються бонуси:**

**На головній сторінці (`index.html`):**
- ✅ Компактно в прогрес-барі: `500₴ 💰🚚🎁 Отримано!`
- ✅ Label змінюється: `🎉 Активні бонуси (3)`

**На сторінці кошика (`cart.html`):**
- ✅ **В підсумку замовлення** (cart-summary-section):
```
🎉 Ваші бонуси:
💰 Знижка 5%                    ✓
🚚 Безкоштовна доставка         ✓
🎁 Подарунок: Міні-листівка     ✓
```
- ✅ Компактно в прогрес-барі

## 🏙️ Геолокація користувача

### Як це працює:

#### 1️⃣ **Автоматичне визначення**
- Сайт запитує дозвіл на геолокацію
- Визначає координати → місто через OpenStreetMap
- Перевіряє доступність доставки
- Зберігає в localStorage (24 години)

#### 2️⃣ **Індикатор в хедері**
```
📍 Київ  ← Клікабельний!
```

**Кольори:**
- 🟢 Зелений = доставка доступна
- 🔴 Червоний = доставка недоступна  
- 🔵 Синій = визначення...

#### 3️⃣ **Зміна міста вручну**
Клікніть на індикатор → відкриється модальне вікно:
- **SELECT**: оберіть зі списку всіх міст
- **АБО**
- **INPUT**: введіть вручну (якщо вашого міста немає)
- **Популярні міста**: швидкий вибір 6 великих міст

## 🎁 Вибір подарунків

### В адмін панелі:

При створенні етапу з подарунком:

1. **SELECT**: оберіть з додаткових товарів
   - Автоматично підтягуються всі товари
   - Показується назва товару
   
2. **АБО Custom input**: введіть свій варіант
   - Наприклад: "Міні-ваза з логотипом"
   - Не обов'язково використовувати існуючий товар

**Пріоритет**: спочатку custom → потім select

## 📁 Налаштування міст доставки

### В `data.json`:

```json
"delivery_cities": [
  {
    "id": 1,
    "name": "Київ",
    "region": "Київська область",
    "delivery_fee": 0,
    "free_delivery_threshold": 800,
    "is_active": true
  }
]
```

### Поля:
- `name` - назва міста
- `region` - область (показується в дужках)
- `delivery_fee` - вартість доставки (грн)
- `free_delivery_threshold` - безкоштовна доставка від (грн)
- `is_active` - чи активне місто

## 🧪 Тестування

### 1. Тест прогрес-бару:
1. Додайте товар в кошик
2. Відкрийте консоль (F12)
3. Побачите:
```
📊 Етап "Знижка 5%": потрібно 500₴, є 0₴, досягнуто: false
📊 Етап "Доставка": потрібно 1000₴, є 0₴, досягнуто: false
```
4. Додавайте товари → бонуси з'являться в підсумку

### 2. Тест геолокації:
1. Відкрийте сайт
2. Дайте дозвіл на геолокацію
3. Побачите індикатор міста в хедері
4. Клікніть → змініть місто

## 🚀 API Endpoints

### Progress Bar:
- `GET /api/progress-bar/` - отримати налаштування
- `POST /admin-panel/api/marketing/progress-bar/toggle/` - увімкнути/вимкнути
- `POST /admin-panel/api/marketing/milestones/add/` - додати етап
- `POST /admin-panel/api/marketing/milestones/<id>/update/` - оновити
- `POST /admin-panel/api/marketing/milestones/<id>/delete/` - видалити
- `GET /admin-panel/api/marketing/milestones/<id>/get/` - отримати дані

### Геолокація:
- `GET /api/delivery-cities/` - список активних міст
