## 🔒 1. БЕЗПЕКА

### 🔴 КРИТИЧНІ ПРОБЛЕМИ (Виправити перед запуском!)

#### 1.1 DEBUG режим увімкнено
```python
# mysite/settings.py
DEBUG = True  # ❌ Має бути False для production!
```
**Ризик:** Викриття конфіденційної інформації (структура БД, шляхи до файлів, змінні середовища)  
**Рішення:**
```python
DEBUG = False  # Production
DEBUG = os.getenv('DEBUG', 'False') == 'True'  # Краще читати з environment
```

#### 1.2 Тестовий SECRET_KEY
```python
SECRET_KEY = 'django-insecure-your-secret-key-here'  # ❌ Тестовий ключ!
```
**Ризик:** Можливість підробки CSRF токенів, сесій  
**Рішення:**
```python
# Згенерувати новий ключ:
from django.core.management.utils import get_random_secret_key
print(get_random_secret_key())

# Зберегти в environment змінній:
SECRET_KEY = os.getenv('SECRET_KEY', 'fallback-key-only-for-dev')
```

#### 1.3 ALLOWED_HOSTS містить wildcard домени
```python
ALLOWED_HOSTS = ['localhost', '127.0.0.1', '.ngrok-free.app', '*.ngrok.io', '.ngrok.app']
```
**Ризик:** Потенційні Host Header атаки  
**Рішення:** Замінити на конкретні домени для production:
```python
ALLOWED_HOSTS = [
    'localhost',  # Тільки для локальної розробки
    '127.0.0.1',
    'your-actual-domain.com',  # Ваш реальний домен
    'www.your-actual-domain.com'
]
```

```python
def validate_image_url(url):
    allowed_domains = ['imgur.com', 'i.pinimg.com', 'your-cdn.com']
    from urllib.parse import urlparse
    domain = urlparse(url).netloc
    return any(d in domain for d in allowed_domains)
```
